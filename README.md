# muse-widget

Muse usage data for an iOS Scriptable widget.

- Only Muse usage. No Codex, no Claude.
- Public on purpose: the widget reads this file, so it only contains numbers anyone could see on a home screen.
- File: `muse-widget.json`
- Raw URL: https://raw.githubusercontent.com/Mahiru0311/muse-widget/main/muse-widget.json
- Updated every 15 minutes by Muse.

Never put tokens, passwords, private chat content, or QQBot status in this repo.
